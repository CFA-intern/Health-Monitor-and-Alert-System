# Health Monitor and Alert System

This is a web-based application designed to monitor patient health vitals such as heart rate, blood pressure, SpO₂, and temperature. The system features role-based dashboards for Admins, Doctors, and Caretakers. It provides real-time alerts when vitals cross normal thresholds, enabling timely care and medical response.

## Features

- Real-time vitals simulation (with auto-updating data)
- Alert generation for abnormal vitals
- Role-based dashboards: Admin, Doctor, Caretaker
- Patient detail view with charts and medical history
- Click-to-call caretakers (simulated)
- Login-based routing
- Deployed using GitHub Pages

## Technologies Used

- React (TypeScript)
- Vite
- Tailwind CSS
- React Router
- React Query
- Recharts
